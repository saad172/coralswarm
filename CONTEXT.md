# CoralSwarm Memory

CoralSwarm brings information from people's and companies' work into a connected memory. This glossary defines the agreed language for that memory.

## Language

**Atom**:
One meaningful fact, decision, action, or observation, linked to its exact source passage.

**Effective time**:
The interval in which a recorded assertion says its state applies. A capture date
or the date we learned a statement does not establish this interval.

**Knowledge time**:
When CoralSwarm records an observation or temporal interpretation. It is distinct
from when the source says something occurred.

**Recorded historical state**:
The states supported by currently readable, accepted temporal assertions at an
effective point, considering only observations recorded by a chosen knowledge
point. Independent contradictory assertions remain contradictory.

**Temporal correction**:
An explicit evidence-bound replacement of a particular recorded assertion or
transition. A more recent capture alone is not a correction.
